Python example

from openai import OpenAI
client = OpenAI(
    base_url="https://agent01-own-api.vercel.app/v1",
    api_key="YOUR_AGENT01_KEY"
)
reply = client.chat.completions.create(
    model="agent01-local",
    messages=[{"role":"user","content":"Hello, Agent 01"}],
    max_tokens=120
)
print(reply.choices[0].message.content)
CPU inference is on-demand and subject to Vercel Hobby limits. Streaming, embeddings, tool calling and 24/7 workers are not included.
