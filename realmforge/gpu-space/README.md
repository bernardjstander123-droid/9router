# RealmForge GPU Worker
Deploy this directory as a Hugging Face Gradio Space. Select ZeroGPU hardware in Space settings if your account is eligible.
This is a real CUDA capability diagnostic and inference smoke test, not a video model. It does not falsely report GPU access on CPU.
Wan 2.2 video inference is a separate integration stage, requiring model files, memory and runtime configuration.
